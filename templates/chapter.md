# 章节模板(书本式)

> **用途:** `.qiling/docs/chapters/chapter-NN-*.md`
> **触发时机:** `/ql-deliver` 成功推送 PR 后自动生成(`/ql-doc`)
> **结构:** 教科书式——**本章导学**(学习目标/前置章节)→ **正文五章**(是什么 → 快速上手 → 怎么用 → 配置限制 → 排错)→ **本章小结 + 下一章**(要点回顾/递进指向)→ **附录三章**(交付留档 / 章节对比 / 数据来源与验证)
> **篇章组织:** 每章 frontmatter 带 `part`(篇名),首页目录按篇分组、按学习顺序排列
> **人工保护区:** `<!-- manual:ID -->` … `<!-- /manual:ID -->` 块内的内容欢迎人工撰写与润色,**重新生成时必须原样保留**(见"人工保护区"约定)

<purpose>

**章节文件**(`chapter-NN-*.md`)是**教科书章 + 留档附录**:

- **本章导学(教学外壳·章首)** —— 学习目标、前置章节、读法建议(教科书"学习目标"惯例;先读小结再读正文是合法读法)
- **正文五章(§一~§五)** —— 是什么 → 快速上手 → 使用说明(参考)→ 配置与限制 → 故障排查;保留 0.17.0 的参考骨架与示例质量
- **本章小结 + 下一章(教学外壳·章末)** —— 要点回顾;按学习路径指向下一章(人工可编排,不必等于交付顺序)
- **附录三章(A~C)** —— 交付留档、章节对比(迁移指南)、数据来源与验证

**篇章组织:** 每章 frontmatter `part` = 篇名;一篇可含多章(同一知识域);首页目录按篇分组。scan 起步章固定归入"第一篇 · 认识项目"。

**核心原则:**

- 章节文档反映**已合并的代码状态**;正文机器节不要手改(改了会被下次 ship 覆盖)
- **人工保护区(`manual` 块)** —— 导学/概述/上手/小结/下一章五处供人工撰写,**重新生成时同 ID 块原样保留**
- 严谨性机制(单一可信源/未检出显式声明/推断标注/不画假图)保留:验证过程与证据说明集中在附录 C

**与 `/ql-scan` 章节的关系:** 共用同一骨架与断言,不得格式分裂。

</purpose>
